# GameCars

Car models extracted from racing games (PlayStation 2, PSP, Xbox, Xbox 360, PC and mobile) and converted to FBX.

**Browse:** https://idbkr.github.io/ - every car, rim and traffic vehicle with a picture and its own download.

The downloads are zips in the [releases of the files repository](https://github.com/IDBKR/GameCars/releases): one release per game,
one zip per model. A whole game at once with the GitHub CLI: `gh release download <game> -R IDBKR/GameCars`.

FBX: Y up, metres, the front of the car towards +Z, textures inside the file (Real Racing 3: in a `textures` folder next to it).
Hidden objects inside the FBX hold body kits, levels of detail and other variants where the game has them.

All cars, models, textures and names belong to their respective owners, the developers and publishers of the games. This is an
unofficial, non-commercial archive for research, preservation and modding, not affiliated with or endorsed by any of them.
Rights holders: open an issue to have something removed.
